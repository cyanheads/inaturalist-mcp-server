# 0.2.2 — 2026-10-08

## Changed

- **Tool errors** — error results carry `data.requestId` and end with `request <id>` (mcp-ts-core 0.13.10). Error `data` no longer carries stack traces, request context, or `rootCause` (mcp-ts-core 0.13.7, 0.13.8, 0.13.13).
- **Argument repair** — a numeric or boolean string, a lone string for a list, or `null` at an optional key is repaired before validation (mcp-ts-core 0.13.14).
- **Recovery hints** — the `ctx.recoveryFor` forwards are removed from the tool handlers and the service's upstream-error mapper. The framework fills each tool's declared `recovery` hint (mcp-ts-core 0.13.10), so callers see the same hints as before.
- **Docker** — production dependencies install in a `deps` stage on the build platform (mcp-ts-core 0.13.10), and musl-only packages are pruned from the image (mcp-ts-core 0.13.11). Bun 1.4.0 → 1.4.2; the image no longer sets `MCP_FORCE_CONSOLE_LOGGING`. `scripts/install-otel.ts` and `scripts/prune-musl-packages.ts` are new.
- **`server.json`** — npm entries drop the `run start:*` arguments and set `runtimeHint: npx`; the `streamable-http` entry sets `MCP_TRANSPORT_TYPE` to `http` (mcp-ts-core 0.13.11). The `INATURALIST_DAILY_REQUEST_BUDGET` description notes the counter is per process and resets on restart.
- **Ignore files** — `.gitignore` and `.dockerignore` cover every `.env*` file (templates stay tracked), and `.dockerignore` adds the MCP Registry token files. `.mcpbignore` excludes `/.cache/`, `/tests/`, `/logs/`, and `/docs/idea.md`. The npm `files` allowlist excludes `dist/*.mcpb`.
- **`.env.example`** — documents `MCP_REQUEST_STATE_KEY`, failed-call payload logging (`LOG_TOOL_FAILURE_PAYLOADS`, `LOG_TOOL_FAILURE_PAYLOAD_MAX_BYTES`), and the OTLP traces, metrics, and logs endpoints.
- **README** — condensed: tool and resource descriptions tightened, the Licensing and attribution, Rate limits and response size, and Known limitations sections removed, the MCP SDK badge `^2.0.0` → `^2.2.0`, Bun badge `v1.4.0` → `v1.4.2`, and the observation count `380M+` → `387M+`.
- **`CLAUDE.md` / `AGENTS.md`** — follow the 0.13.14 agent protocol (error contract, `ctx.state`, `ctx.requestId`, release PR body).
- **CodeQL workflow** — runs one job per language, uploading under `/language:<language>`.
- **Framework skills and scripts** — `framework-skills/` and the `lint-mcp`, `lint-packaging`, `devcheck`, `release-github`, `check-skill-versions`, and `check-framework-antipatterns` scripts re-synced to mcp-ts-core 0.13.14.
