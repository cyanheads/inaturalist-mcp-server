# 0.2.1 — 2026-09-23

## Added

- **`user_id`, `user_login`, `project_id`** — `inaturalist_search_observations` and `inaturalist_get_species_counts` filter by observer or project, resolved via `inaturalist_resolve_name`; a paired `user_id` + `user_login` mismatch fails in-process as `conflicting_observer` ([#14](https://github.com/cyanheads/inaturalist-mcp-server/issues/14)).
- **`license`, `photo_license`** — `inaturalist_search_observations` filters by the seven CC licence codes ([#20](https://github.com/cyanheads/inaturalist-mcp-server/issues/20)).
- **`term_id`, `term_value_id`, `iconic_taxa`** — `inaturalist_get_histogram` charts one annotation value or iconic-taxa group; `inaturalist_list_reference`'s `observed_usage` rows now carry the ids that feed them ([#19](https://github.com/cyanheads/inaturalist-mcp-server/issues/19)).
- **`position`** — `inaturalist_get_species_counts` rows carry an absolute rank counted from page 1, and `format()` numbers from it instead of the page-local index ([#8](https://github.com/cyanheads/inaturalist-mcp-server/issues/8)).

## Fixed

- **`inaturalist_search_observations`** `next_cursor` is now issued and honored only under `order_by: "id", order: "desc"`; any other ordering raises `page` instead, and the `result_window_exceeded` recovery names the id-desc re-run ([#7](https://github.com/cyanheads/inaturalist-mcp-server/issues/7)).
- **`inaturalist_search_observations`, `inaturalist_get_species_counts`, `inaturalist_get_leaderboard`** — a page past the end, with a nonzero total, now names the last page holding results instead of reporting zero matches ([#27](https://github.com/cyanheads/inaturalist-mcp-server/issues/27)).
