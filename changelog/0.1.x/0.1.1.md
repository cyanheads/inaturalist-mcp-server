# 0.1.1 — 2026-09-19

## Added

- **Ten read-only tools over the iNaturalist v1 API**, keyless throughout: `inaturalist_list_reference`, `inaturalist_resolve_name`, `inaturalist_find_places`, `inaturalist_search_observations`, `inaturalist_get_observation`, `inaturalist_get_species_counts`, `inaturalist_get_histogram`, `inaturalist_get_leaderboard`, `inaturalist_get_similar_species`, `inaturalist_get_taxon`.
- **Two resources** — `inaturalist://taxa/{taxon_id}` and `inaturalist://observations/{observation_id}` — mirroring `inaturalist_get_taxon` and `inaturalist_get_observation` for clients that inject context rather than call tools.
- **In-process response projection.** Upstream accepts and ignores its own `fields=` parameter, so every payload is fetched whole and trimmed here — two observations measure 94,872 bytes raw, a common taxon record 95 KB. `inaturalist_get_taxon` returns `kind: "outline"` with per-section byte sizes when the projected document still overflows the 24,000-byte budget.
- **Per-endpoint parameter allowlist and in-process filter validation.** An unknown parameter name returns HTTP 200 and the entire global index, so nothing outside the allowlist is sent, and a lone `lat`, two area forms at once, an unparseable `d1`, a `term_value_id` without its `term_id`, or a page past the 10,000-result window fails before any request goes out.
- **Byte-sized page caps.** `per_page` maxima come from measured response bytes rather than what upstream will serve — 25 for `inaturalist_search_observations`, 50 for `inaturalist_get_species_counts`, 250 for `inaturalist_get_leaderboard` — and `inaturalist_get_histogram` caps `buckets[]` at 800 while `total` still sums every bucket upstream returned.
- **Unconditional truncation disclosure.** Every list tool writes `truncated`, `shown`, and `cap` on every path, zero-hit and under-cap pages included, alongside an applied-filter echo and a zero-hit notice naming the filter most likely responsible.
- **Licence and attribution relayed per record.** `license_code` is nullable and never coerced — a null means all rights reserved — photo `attribution` is reproduced verbatim, photos are linked rather than proxied, and an obscured coordinate is rendered as a locality.
- **Self-paced outbound traffic.** No rate-limit headers come back, so four optional env vars set the posture: `INATURALIST_USER_AGENT`, `INATURALIST_MIN_REQUEST_INTERVAL_MS` (1100 ms ≈ 54/min), `INATURALIST_MAX_CONCURRENT_REQUESTS` (4), and `INATURALIST_DAILY_REQUEST_BUDGET` (9000 per UTC day; exhaustion is a typed failure).
- **Tenant-scoped caching on the slow-moving surfaces** — controlled terms 24 h, taxa, places, and the similar-species graph 6 h, histograms 1 h. Observation search, species counts, leaderboards, and observation detail are never cached.
