# 0.1.3 — 2026-09-22

## Fixed

- **`invalid_geography`** now also rejects a `radius` of 0 or less and a bounding box with `nelat` south of `swlat`, both of which upstream previously answered with a retried HTTP 500 ([#16](https://github.com/cyanheads/inaturalist-mcp-server/issues/16)).
- **`d1`/`d2`** reject a calendar-invalid date (e.g. `2026-02-30`) at the schema, beside the existing pattern check ([#15](https://github.com/cyanheads/inaturalist-mcp-server/issues/15)), and a `d1` after `d2` now fails as `inverted_date_range` on every tool that takes dates, instead of narrowing to zero results with no signal ([#11](https://github.com/cyanheads/inaturalist-mcp-server/issues/11)).
- **`hrank`/`lrank`** on `inaturalist_search_observations` now compare by upstream rank level rather than list position, and an `hrank` finer than `lrank` fails as `inverted_rank_range` instead of matching nothing ([#11](https://github.com/cyanheads/inaturalist-mcp-server/issues/11)).
- **`inaturalist_find_places`** bounding-box arm: `truncated`/`cap` now account for `per_page` bounding the standard and community lists separately, so `shown` can no longer exceed `cap` ([#10](https://github.com/cyanheads/inaturalist-mcp-server/issues/10)); a blank `q` is read as unset instead of rejecting the call ([#13](https://github.com/cyanheads/inaturalist-mcp-server/issues/13)).
- **`inaturalist_resolve_name`**: `limit` is now enforced on the taxon route, which upstream can exceed on its own ([#12](https://github.com/cyanheads/inaturalist-mcp-server/issues/12)); a `user` candidate now also carries `login`, the identifier leaderboard entries and an observation's `observer` relay, with `name` documented as the display name ([#9](https://github.com/cyanheads/inaturalist-mcp-server/issues/9)).
- **Zero-hit notices** (`inaturalist_get_histogram`, `inaturalist_resolve_name`, `inaturalist_get_species_counts`, `inaturalist_get_leaderboard`, `inaturalist_get_similar_species`, `inaturalist_search_observations`) now name only the filters the call actually supplied, instead of pointing at ones it never set ([#22](https://github.com/cyanheads/inaturalist-mcp-server/issues/22)).
