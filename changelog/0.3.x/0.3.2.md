# 0.3.2 — 2026-10-31

## Changed

- **`inaturalist-guide` 1.1 → 1.2** covers name browsing, histogram continuation, and shared identification evidence.

## Fixed

- **Name resolution** discloses truncation and supports explicit pages; taxon-name browsing uses ascending IDs and may match a different multilingual population from autocomplete. Numeric IDs remain singleton lookups. ([#58](https://github.com/cyanheads/inaturalist-mcp-server/issues/58))
- **Name matching guidance** describes taxon word starts, analyzed place terms, and limited cross-kind spelling tolerance. ([#46](https://github.com/cyanheads/inaturalist-mcp-server/issues/46))
- **Place queries** forward `per_page` for names, serving up to 20 matches without offsets. ([#60](https://github.com/cyanheads/inaturalist-mcp-server/issues/60))
- **Upstream slices** disclose the 20-place and 24-neighbor served ceilings; strict mode still accepts historical maxima of 30 and 50. ([#45](https://github.com/cyanheads/inaturalist-mcp-server/issues/45))
- **`misidentification_count`** retains its values and now describes symmetric co-identification evidence, including ancestors, rather than directional corrections. ([#44](https://github.com/cyanheads/inaturalist-mcp-server/issues/44))
- **Absolute histograms** disclose calendar-based window starts and retain up to 25,000 buckets, with totals across the full upstream window. Continuation preserves earlier repeated-key counts; partial boundary buckets cannot reconstruct complete totals. The row cap is no byte guarantee. ([#43](https://github.com/cyanheads/inaturalist-mcp-server/issues/43))
