# 0.3.3 — 2026-11-11

## Added

- **`inaturalist_get_observation` thread paging** takes `array_offset` and `array_limit` (default 40, ceiling 1,500) over identifications, comments, and observation fields; one response-level `next_array_offset` continues every array. ([#48](https://github.com/cyanheads/inaturalist-mcp-server/issues/48))
- **`hidden`** on identifications and comments, with `identifications_hidden` / `comments_hidden` counting the whole array on every page. ([#61](https://github.com/cyanheads/inaturalist-mcp-server/issues/61))
- **Observation fields** carry `datatype` and, when upstream resolved one, a five-field `taxon`. ([#56](https://github.com/cyanheads/inaturalist-mcp-server/issues/56))
- **`outlinks`** (`source`, `url`) on every observation record, such as its GBIF occurrence; search counts them inside its 50,000-byte reply budget. ([#69](https://github.com/cyanheads/inaturalist-mcp-server/issues/69))
- **`ident_user_id` and `unobserved_by_user_id`** filters on `inaturalist_search_observations` and `inaturalist_get_species_counts`, each an id or login. ([#70](https://github.com/cyanheads/inaturalist-mcp-server/issues/70))
- **Inactive taxa** carry `is_active` and `current_synonymous_taxon_ids` on `inaturalist_get_taxon` and `inaturalist_resolve_name`. ([#57](https://github.com/cyanheads/inaturalist-mcp-server/issues/57))
- **Conservation statuses** carry `iucn_code`; the `conservation_status_codes` reference topic lists nine levels, `NE` and `DD` included (not valid as `csi`). ([#71](https://github.com/cyanheads/inaturalist-mcp-server/issues/71))
- **`rate_budget_exhausted`** is declared on every tool, so `tools/list` advertises it. ([#63](https://github.com/cyanheads/inaturalist-mcp-server/issues/63))

## Changed

- **By-id thread arrays** sort by ascending `id` instead of upstream order. ([#48](https://github.com/cyanheads/inaturalist-mcp-server/issues/48))
- **`captive: true`** without `"casual"` in `quality_grade` adds a notice on search, species counts, histogram, and similar species that the cohort is grade-inconsistent. ([#67](https://github.com/cyanheads/inaturalist-mcp-server/issues/67))
- **Zero-hit guidance** on search and species counts names every supplied filter in a fixed order; an exhausted cursor walk says it is complete. ([#68](https://github.com/cyanheads/inaturalist-mcp-server/issues/68))
- **Resource misses** are a typed `not_found` carrying a recovery hint. ([#63](https://github.com/cyanheads/inaturalist-mcp-server/issues/63))
- **`unknown_user`** recovery covers all four user selectors.
- **Advertised descriptions** drop clauses that narrate upstream behavior or payload sizes, keeping each field's constraint. ([#73](https://github.com/cyanheads/inaturalist-mcp-server/issues/73))
- **`initialize`** serves `serverInfo.description`.
- **Unmapped upstream error bodies** no longer reach `structuredContent.error.data.body` (framework 0.13.22).

## Fixed

- **Histogram** zero-bucket wording.
- **`global_status`** renders `none published` instead of an empty value.
- **A full final cursor page** no longer reports `has_more: true`.
