# 0.3.0 — 2026-10-26

## Added

- Serve the inaturalist-guide skill over MCP for observation, phenology, and identification workflows.

## Changed

- **Search response budget** — return a whole-record prefix within 50,000 serialized UTF-8 bytes, with ordered `deferred` IDs for by-id retrieval using the same `include`; pagination follows the complete upstream page. (#28)
- **Read limits** — clamp oversized list limits to their existing ceilings, with a notice, log, and counter; `INATURALIST_CLAMP_LIMITS=false` restores strict validation and advertised caps. (#37)
- **By-id batches** — accept up to 100 submitted IDs, deduplicate in request order, attempt ten distinct IDs, and return the remaining IDs in `deferred`, separate from attempted misses. The strict switch restores ten submitted IDs. (#41)
- **Search schema** — omit twelve unreachable detail fields and condense descriptions while retaining all emitted fields and media expansions; detail and resource schemas remain complete. (#39)
- **Packaging and tooling** — add Agent Plugins root manifests, sync framework skills/scripts, validate published skills, and preserve SDK runtime skills modules during MCPB cleanup. Bun 1.4.2 → 1.4.4; minimum dependency age is one day.

## Fixed

- **Histogram date bounds** — accept independent `created_d1`/`created_d2` upload-date filters, validate inverted ranges, and distinguish them from observation dates and bucketing. (#31)
- **Filter guidance** — describe captive and wild selections as exclusive cohorts, disclose ignored empty filter arrays, and normalize repeated quality grades in first-seen order. (#32, #33)
- **Unknown places** — return typed `unknown_place_id` errors with place-discovery recovery on every area-filter tool. (#34)
- **Leaderboard continuation** — an exactly full final page reports no further page, including at the 500-entry ceiling. (#35)
- **Literal rendering** — preserve upstream strings, line separators, whitespace, HTML, and entities after CommonMark parsing; render URLs as links and label NUL-containing strings as JSON literals. (#36)
- **Empty evidence** — show present-empty expansions, zero observation-field counts, and distinct absent, null, and empty descriptions in rendered tool results. (#40)
- **Audio discovery** — forward the optional `sounds` boolean on observation search, independently of sound expansion, and name it in zero-hit guidance. (#38)
