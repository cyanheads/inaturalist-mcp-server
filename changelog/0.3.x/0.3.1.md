# 0.3.1 — 2026-10-31

## Added

- **Species-count filters** support establishment, conservation status, rank bands, exact rank, and observed months; search shares the month filter ([#51](https://github.com/cyanheads/inaturalist-mcp-server/issues/51)).
- **Observation search** supports accuracy, obscuration, upload-date, update-time, and identification-agreement filters; search, detail, and resource records preserve full nullable `created_at` and `updated_at` strings ([#52](https://github.com/cyanheads/inaturalist-mcp-server/issues/52)).
- **Histogram and leaderboard scope** accepts observer or project selectors, with typed name-resolution recovery; identifier rankings describe contributors to the selected observer's sightings ([#54](https://github.com/cyanheads/inaturalist-mcp-server/issues/54)).
- **Taxon ranks** include ten supplemental upstream ranks, including `complex` and `section`, with fractional rank levels preserved ([#55](https://github.com/cyanheads/inaturalist-mcp-server/issues/55)).

## Changed

- **Radius searches** accept regional and continental areas, clamping above 20,040 km with notice, log, and counter; `INATURALIST_CLAMP_LIMITS=false` retains the 500 km ceiling ([#62](https://github.com/cyanheads/inaturalist-mcp-server/issues/62)).
- **`inaturalist-guide` 1.0 → 1.1** explains leaf-taxon rankings, matched observer/project cohorts, and annotation-intersection workflows.

## Fixed

- **Taxon rankings** label totals and notices as taxa, including hybrids and coarser identifications; `species` remains the array name ([#47](https://github.com/cyanheads/inaturalist-mcp-server/issues/47)).
- **Annotation arrays** disclose membership-set union semantics when multiple distinct attributes or values are supplied ([#50](https://github.com/cyanheads/inaturalist-mcp-server/issues/50)).
- **Cursor and project validation** rejects values above 2,147,483,647 before upstream requests ([#59](https://github.com/cyanheads/inaturalist-mcp-server/issues/59)).
- **Blank optional enums** read as omitted, applying existing defaults while retaining advertised enum schemas ([#64](https://github.com/cyanheads/inaturalist-mcp-server/issues/64)).

## Dependencies

- `@biomejs/biome` 2.6.3 → 2.6.4.
- `@types/node` 26.6.5 → 26.6.6.
